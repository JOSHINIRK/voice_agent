# Mini Voice Agent (Whisper + GPT + TTS)

A voice assistant: you **speak** a question, **Whisper** transcribes it, **GPT** answers, and the answer is **spoken back** with OpenAI text-to-speech. Every turn is logged with its text, audio and per-stage timing.

```
 🎙️ browser mic / audio file / terminal mic
        │  WAV / WebM / MP3 ...
        ▼
 ┌──────────────┐   text   ┌──────────────────────────────┐  reply text  ┌────────────────┐
 │ Whisper STT  │ ───────► │ Chatbot logic                │ ───────────► │ TTS            │──► 🔊 playback
 │ whisper-1    │          │  • empty / too-short check   │              │ gpt-4o-mini-tts│
 └──────────────┘          │  • voice commands (repeat,   │              └────────────────┘
                           │    start over, goodbye)      │
                           │  • memory: last 6 exchanges  │
                           │  • GPT (gpt-4.1-mini) with a │
                           │    "speak briefly" prompt    │
                           │  • strip markdown for speech │
                           └──────────────────────────────┘
                                         │
                                         ▼
                 logs/conversations/<session>.jsonl  +  logs/audio/<session>/turnNN_*.wav|mp3
```

## Deliverables

| Deliverable | Where |
|---|---|
| End-to-end voice interaction flow | [voiceagent/agent.py](voiceagent/agent.py) `VoiceAgent.handle_audio()`: STT → chatbot/GPT → TTS |
| Interface for recording and playback | [app.py](app.py) (Streamlit web app) and [scripts/talk.py](scripts/talk.py) (terminal) |
| Sample conversations logged | [samples/conversations/](samples/conversations/), generated by [scripts/make_samples.py](scripts/make_samples.py); every live session is also logged to `logs/` |
| Demo video | Record it with the guide in [docs/DEMO_VIDEO.md](docs/DEMO_VIDEO.md) |

## 1. Quick start

You need Python 3.11+ and an OpenAI API key with credit (the same key as the other projects works).

```powershell
cd E:\Joshini_tcs\TCS_Projects\voice_agent
py -3 -m venv .venv                                  # skip if .venv already exists
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
notepad .env                                         # paste your key after OPENAI_API_KEY=
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Open http://localhost:8501, allow microphone access when the browser asks, then click the mic and speak.

> **Windows:** start the app with `python -m streamlit`, not `streamlit.exe`; Smart App Control blocks the unsigned launcher.
> The microphone works on `localhost` (or HTTPS) only; browsers block it on plain-HTTP network addresses.

## 2. Using the app

**Talk tab**
- **Record your question:** click the mic, speak, click stop. The recording is sent straight away.
- The reply appears as text and **plays automatically**. Your own recording can be replayed too.
- Under each reply: the time for each stage (`STT`, `LLM`, `TTS`) and who answered (GPT or a built-in command).
- **Upload an audio file** (wav, mp3, m4a, webm, ...) or **type** in the chat box as alternatives; typed questions still get a spoken reply.
- On an empty conversation, three sample prompt buttons get you started.

**Sidebar:** choose one of 10 voices, turn speech or auto-play off, start a new conversation, download the current session as Markdown or JSON Lines.

**Conversation logs tab:** browse every past session with turn count, average response time, tokens used, the transcript and the reply audio.

### Voice commands (handled locally, no GPT call)

| Say | Effect |
|---|---|
| "Repeat that" / "Say that again" / "Pardon?" | Replays the last answer |
| "Start over" / "Clear the conversation" | Clears the conversation memory |
| "Goodbye" / "That's all, thanks" / "Stop" | Says goodbye and ends the conversation |

A command must be the **whole** utterance, so "Can you repeat the history of Rome?" still goes to GPT.

## 3. Terminal mode

```powershell
.\.venv\Scripts\python.exe scripts\talk.py --text               # type, hear spoken replies
.\.venv\Scripts\python.exe scripts\talk.py --file q1.wav q2.m4a # send recordings
.\.venv\Scripts\python.exe -m pip install sounddevice           # optional, for live mic in terminal
.\.venv\Scripts\python.exe scripts\talk.py                      # push-to-talk: Enter to start, Enter to stop
```

Replies are played with Python's built-in `winsound`, so no media player is needed.

## 4. How it works

| Step | File | Details |
|---|---|---|
| Record | [app.py](app.py) | `st.audio_input` records WAV in the browser; no PyAudio or ffmpeg needed |
| Speech-to-text | [voiceagent/speech.py](voiceagent/speech.py) | `client.audio.transcriptions.create(model="whisper-1", language="en")`. Checks the format and the 25 MB limit; recordings under 2 KB are treated as silence and never sent |
| Chatbot logic | [voiceagent/chat.py](voiceagent/chat.py) | Empty transcript → "didn't catch that"; regex voice commands; otherwise GPT with a voice-specific system prompt (1–3 sentences, no markdown, current date/time) and the last 6 exchanges. Replies are cleaned of markdown, links and list markers before speaking |
| Text-to-speech | [voiceagent/speech.py](voiceagent/speech.py) | `client.audio.speech.create(model="gpt-4o-mini-tts", voice=..., instructions=...)`. If TTS fails, the text reply is still shown |
| Logging | [voiceagent/logger.py](voiceagent/logger.py) | One JSON line per turn: user text, reply, source, per-stage timings, tokens, models, voice, and paths to both audio files |

Example log line:

```json
{"session": "20261117-212313-78f1", "turn": 2, "input_mode": "voice",
 "user": "Why is the sky blue?", "assistant": "Sunlight scatters off air molecules...",
 "source": "gpt", "timings_s": {"stt": 0.81, "llm": 1.12, "tts": 1.35}, "total_s": 3.28,
 "tokens": 214, "models": {"stt": "whisper-1", "chat": "gpt-4.1-mini", "tts": "gpt-4o-mini-tts", "voice": "alloy"},
 "user_audio": "audio/20261117-212313-78f1/turn02_user.wav",
 "assistant_audio": "audio/20261117-212313-78f1/turn02_assistant.mp3"}
```

## 5. Sample conversations

```powershell
.\.venv\Scripts\python.exe scripts\make_samples.py
```

This runs three scripted conversations through the **real** pipeline. Each question is first spoken with a different TTS voice ("echo") to stand in for a microphone, then transcribed by Whisper, answered and spoken back. Output:

- `samples/conversations/<name>.md`: readable transcript with timings
- `samples/conversations/<name>.jsonl`: the raw log
- `samples/audio/<name>/`: every question and reply as audio

The three conversations cover: general knowledge with follow-ups (memory), study help with **repeat** and **start over** (showing the memory is really cleared), and everyday questions including one it can't answer (live weather) and a **goodbye**. The run costs a few US cents.

## 6. Configuration

All settings are in [config.yaml](config.yaml); any key can be overridden with an environment variable `VOICE_<KEY>`, e.g. `$env:VOICE_TTS_VOICE="nova"`.

| Key | Default | Notes |
|---|---|---|
| `stt_model` | `whisper-1` | or `gpt-4o-transcribe`, `gpt-4o-mini-transcribe` |
| `stt_language` | `en` | empty = auto-detect (multilingual) |
| `chat_model` | `gpt-4.1-mini` | for reasoning models set `temperature: null` |
| `history_turns` | `6` | exchanges kept in memory |
| `tts_model` / `tts_voice` | `gpt-4o-mini-tts` / `alloy` | `tts-1` is cheaper; `tts_instructions` only applies to gpt-4o TTS |
| `system_prompt` | voice-style prompt | `{name}` and `{now}` are filled in |
| `save_audio` | `true` | set `false` to log text only |

## 9. Troubleshooting

| Problem | Fix |
|---|---|
| "No OpenAI API key found" | Create `.env` from `.env.example` and restart |
| Mic button does nothing | Allow microphone access in the browser (lock icon in the address bar); use `http://localhost:8501` |
| Reply doesn't play automatically | Browsers block autoplay until you've interacted with the page; click play once, after that it auto-plays |
| `401` / `insufficient_quota` | Check the key and your credit at platform.openai.com |
| Whisper returns odd text for silence | Speak for at least a second; very short clips are ignored |

## 10. Limitations

- Turn-based, not streaming: you finish speaking, then the reply is generated. Typical latency is 2–5 s (Whisper ~1 s, GPT ~1–2 s, TTS ~1–2 s).
- No live data (weather, news): the assistant says so instead of guessing.
- Recordings and transcripts are stored locally in `logs/`; delete the folder to remove them. Audio is sent to OpenAI for transcription.
